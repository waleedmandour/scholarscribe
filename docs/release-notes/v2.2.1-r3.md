# v2.2.1-r3 (Pre-release)

Released: 2026-10-13. Base version 2.2.1, third pre-release revision (r3),
published as a pre-release awaiting maintainer approval. Machine version
fields stay numeric `2.2.1` (Windows MSI constraint); the r3 identity travels
with the tag and release name (see docs/DECISIONS.md).

## What changed

- **About under Get started.** The About page moved directly under the Get
  started section in the sidebar (Models, then About); the welcome tour order
  was updated to match.
- **Ollama status card (Models page).** A live status card directly below the
  PC specs shows whether the local Ollama daemon is reachable at
  `127.0.0.1:11434`: connected (daemon version, installed model count,
  endpoint) or not detected (setup steps + Re-check). The page re-probes
  every 15 seconds while open. Loopback only; no new hosts
  (docs/NETWORK_SURFACE.json unchanged, CI-verified).
- **Model search (Models page).** Live local-only search filtering both the
  installed-models table and the recommended catalog by name, tag, or
  description, with match counts and no-match states.
- **docx to LaTeX (Text Cleaner page).** New "Convert to LaTeX (.tex)" action
  for loaded .docx files: deterministic structural mapping (Title/Heading1-6,
  itemize lists, \textbf/\emph runs, tabular grids, full LaTeX escaping,
  `w:br` → `\\`). Unmapped styles and merged/nested table constructs surface
  in a warnings card. No network, no LLM. 4 new Rust tests cover escaping,
  the structural mapping, unknown-style warnings, and corrupt-file rejection.
- **Intel macOS builds are back.** The macos-13 Intel runner queue is
  unavailable for this repository (v2.2.1's job queued for 24h and was
  auto-cancelled, so v2.2.1 shipped without Intel assets). The Intel leg now
  cross-compiles on the Apple Silicon runner
  (`--target x86_64-apple-darwin`); a one-off `release-intel-mac.yml`
  workflow backfilled the Intel assets onto v2.2.1-r2.
- **Dependencies (npm).** Combined bump resolving the mutually conflicting
  dependabot PRs: svelte ^5.57.2, @sveltejs/vite-plugin-svelte ^7.3.1,
  vite ^8.3.4 (postcss 8.5.29 included via the regenerated lockfile).
  svelte-check stays at 0 errors / 11 warnings.

## Verification

Gated on: `npm ci`, `npm run check` (0 errors / 11 warnings, unchanged),
`npm run build`, `npm test` (references, network surface, cross-language
