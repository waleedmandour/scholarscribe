# v2.2.1-r4 (Pre-release)

Released: 2026-10-13. Base version 2.2.1, fourth pre-release revision (r4),
published as a pre-release awaiting maintainer approval. Machine version
fields stay numeric `2.2.1` (Windows MSI constraint); the r4 identity travels
with the tag and release name (see docs/DECISIONS.md).

## Critical fix

- **White screen at startup.** The r3 installers opened to a blank white
  window. Root cause: `src/main.ts` still created the root component with the
  Svelte 4 style `new App({ target })`. Under the Svelte 5 runtime shipped
  since r2 (svelte 5.57.x), that call throws `effect_orphan` before anything
  renders. The fix mounts the app with `mount(App, { target })`, the Svelte 5
  API. Verified three ways: a headless reproduction against the r3 bundle
  (empty `#app`, `effect_orphan` thrown), the same harness after the fix
  (full shell, all 20 pages mount, first-launch tour renders), and a new
  permanent CI gate (`check-svelte-mount`) that fails if the legacy
  instantiation ever returns.

## UI polish

- **One icon set everywhere.** Sidebar tabs, page headers, the theme toggle,
  and the welcome tour use a single inline SVG set: stroke based,
  currentColor, no emoji, no external assets, CSP safe.
- **Consistent page headers.** All 20 pages open with a shared header: icon
  badge matching the sidebar icon, page title, and lead paragraph.
- **Refined tokens.** Layered light and dark palettes, tighter heading
  tracking, uppercase group labels with wider tracking, active-tab accent
  bar, themed thin scrollbars, focus-visible outlines, table row hover, and
  a reduced-motion guard. Existing class names are preserved so every page
  keeps its layout.
- **Copy corrections.** Sidebar footer now says "v2.2.1 r4"; About's module
  list is seven entries with full-sentence punctuation and now mentions the
  docx to LaTeX conversion; the tour's stale "New in 2.1.0" step title is
  now the evergreen "Evidence: Writing Provenance"; the About tour invite
  says 6 steps, matching the tour.
- **Descriptions.** No em dashes and no en dashes in any user-facing string
  or in this release description.

## Carry-over from r3 (unchanged in this release)

- About sits directly under the Get started section (Models, then About).
- Models page: live Ollama status card below the PC specs (daemon version,
  installed model count, loopback endpoint) with a 15 second re-probe.
- Models page: local-only search over installed and recommended models.
- Text Cleaner: docx to LaTeX conversion with deterministic structural
  mapping and a warnings card for unmapped constructs.
- Intel macOS assets build on the Apple Silicon runner via cross-compile.
