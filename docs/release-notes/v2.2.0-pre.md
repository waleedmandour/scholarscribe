# ScholarScribe v2.2.0-pre (Pre-release), 29 September 2026

> Backfilled on 13 October 2026 from `git log v2.1.0..v2.2.0-pre` and the code. The original release notes for this pre-release were boilerplate and repeated the inaccurate "Single outbound host" privacy claim; this document replaces that text with an honest summary. The same corrected text has been published to the GitHub release.

## What changed (from v2.1.0)

- **Sidebar reorganization**: the 20 tabs are now grouped into 7 workflow phases, with a density toggle (commit `4074638`).
- **Authenticity Risk Profile**: rewritten flagged-passage presentation, backend and frontend (commit `a931672`).
- **Statistics and citations**: source links and "Last verified" dates added to checkable statistics (commit `8a58229`).
- **Scalable font sizes** across the UI (commit `6cbf103`).
- **Copy pass**: em/en dashes removed from user-facing copy; a dash-normalization option added to the AI Text Cleaner (commit `c3fab98`). Note (added 2026-10-13): this sweep mangled at least three sentences in README, USER_GUIDE and USER_MANUAL; the damage was fixed in v2.2.1 r2 and the dash "gate" was retired.
- **README and CHANGELOG**: feature grouping, statistics, accessibility updates; CHANGELOG.md added (commit `33df1d7`).
- **Version bump to 2.2.0**; two-target macOS build (Apple Silicon + Intel); clippy attempted strict, then restored to informational mode because pre-existing warnings blocked it (commits `1b10639`, `fa047d5`, `687352b`, `75a9cd8`).

## Known caveats found later

- The release notes shipped with this pre-release claimed "Single outbound host (registry.ollama.ai)". That was already false: the Google Docs bridge (v2.1.0) contacts Google's OAuth/Drive endpoints on opt-in, and Hugging Face GGUF pulls make the Ollama daemon contact `hf.co`. Corrected in v2.2.1 r2; see `docs/NETWORK_SURFACE.json`.
- Clippy warnings were tracked as debt rather than fixed; resolved in v2.2.1 r2 (warnings fixed, `-D warnings` enforced).
