## What changed (from v2.2.0-pre)

- **Chat**: file picker so you can ground the conversation in a document; Socratic-only chat mode (commit `a865d43`).
- **Voice Check** (voice consistency): computed excerpts shown alongside flags (commits `ba1eb66`, `14b4b46`).
- **Structure Analyzer**: heading-level excerpts for faster review (commit `a865d43`).
- **Citation Manager**: paste references directly for checking (commit `a865d43`).
- **User Guide PDF**: polished generation pipeline (commit `a865d43`).
- **Packaging**: Intel Mac builds, `.rpm` packages, `CHECKSUMS.txt` (SHA-256, unsigned at this point), and CI gates `npm run check`, `npm run build`, `cargo fmt --check`, `cargo check` (release workflow).
- The v2.2.1 USER_GUIDE correctly described the Google Docs bridge network behavior; README, SECURITY and the release notes did not (fixed in v2.2.1 r2).

## Known caveats found later

- "Single outbound host (registry.ollama.ai)" in the original notes was false for the same reasons as v2.2.0-pre (opt-in Google bridge; daemon-side hf.co pulls). Corrected in v2.2.1 r2.
- `SECURITY.md` still listed "TBD" as the security contact and claimed all outbound HTTP lived in `ollama.rs`; both fixed in v2.2.1 r2.
- The verifier cross-language test promised by `docs/PROVENANCE_SPEC.md` did not exist in this release; added in v2.2.1 r2.
