ScholarScribe Provenance Verifier

Standalone checker for ScholarScribe Writing Provenance packages. Runs entirely in your browser — no uploads, no network calls (libraries are bundled locally).

1 · Load a provenance package

…or load a bare manifest.json

2 · Provide the author's public key

Paste the ed25519-pub:{hex} string (or the fingerprint's author key file) that the author exported from ScholarScribe. The verifier also checks that this key matches the fingerprint inside the manifest.

load .pub.json exported by the app

3 · Optionally bind the original document

For a .docx source: the verifier hashes word/document.xml and compares it to the manifest's document_hash. For a Google Docs source: export the document as plain text (.txt) from Google and load it — the hash of that text is compared instead.

optional — original .docx or exported .txt

Verification result

What a passing check means: the package is intact since it was produced by the holder of the signing key, and its internal hash chain is consistent. What it does not mean: the text is human-written, or the authorship is proven. See disclosure.txt inside the package and docs/PROVENANCE_SPEC.md in the repository.
